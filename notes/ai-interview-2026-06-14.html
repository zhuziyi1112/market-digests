Executive Summary

  • Anthropic 6/9 发布 Claude Fable 5 / Mythos 5，强调 1M context、128k max output、always-on adaptive thinking 与 refusal/fallback API 行为；6/12 又出现美国政府出口管制暂停访问声明。面试上需要补充“长上下文 + 安全拒答 + 政策可用性”的组合讨论。
  • OpenAI API 6 月继续围绕 Responses API 增强：web search image results、generation-time moderation scores、prompt/Evals/Agent Builder deprecations、container session 按分钟计费、AWS Bedrock OpenAI-compatible Responses endpoint。面试重点从“会调用模型”进一步转向“会做成本、迁移、治理和多云 API 兼容设计”。
  • vLLM v0.23.0 6/12 发布，DeepSeek-V4、Model Runner V2、Rust frontend、Gemma 4、Transformers v5、KV cache offloading 与 OpenAI/Responses API 兼容都有明显推进；本地/自托管推理题应更新到“生产级 serving + cache/offload + parser/API compatibility”。

Market Signals Worth Watching

  • OpenAI / Anthropic / Google 都在把“模型能力”与“runtime/control plane”绑得更紧：Responses API、container sessions、Managed Agents、Claude self-hosted sandbox endpoint。这意味着 AI Engineer 面试会更偏系统设计与平台治理。
  • Model deprecation / regional availability / export controls 正在成为真实生产风险。候选人需要能讲出 model abstraction、fallback eval、availability monitoring、compliance gate，而不是只会换 provider。
  • Vector DB 与 RAG infra 从“检索能用”走向多租户、agent memory、nested metadata filtering、runtime reindex 和备份可靠性；RAG 题应从 toy demo 升级到 production constraints。

New Interview Questions to Add

  1. 你的生产系统依赖 gemini-2.0-flash，官方宣布 shut down 并建议迁移到 gemini-3.5-flash / gemini-3.1-flash-lite。请设计迁移流程：版本 pinning、回归 eval、fallback、灰度、监控和 rollback。
  2. Claude API 新模型返回 stop_reason: refusal，并支持 beta fallback rerun。你会如何设计业务层的拒答处理、fallback 策略、成本控制和审计日志？
  3. OpenAI Responses API web search 现在可返回 image results。你会如何构建一个图文 evidence-grounded QA 系统，并评估回答是否真的被证据支持？
  4. vLLM v0.23.0 支持多层 KV cache offloading 和更统一的 reasoning/tool parser。请解释 KV cache offload 的收益/风险，以及它如何影响吞吐、延迟和成本。
  5. Weaviate v1.38 引入 Namespaces preview、nested object filtering、Secure MCP server preview。请设计一个多租户 agent memory/RAG 系统，说明权限、隔离、schema migration、backup 和 MCP tool 边界。
  6. OpenAI container sessions 改为按分钟计费且 5 分钟 minimum。如何优化 agent sandbox 的 session lifecycle，避免成本失控？
