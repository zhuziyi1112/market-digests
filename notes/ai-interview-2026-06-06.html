Executive Summary

  • OpenAI 6/4 发布 ChatGPT “Dreaming” memory 方向；AI 面试中的 personalization / memory / context freshness / privacy control 需要从“长期记忆可用”升级到“记忆生命周期与治理”。
  • Anthropic Claude Opus 4.8（5/28）与 Project Glasswing 扩展（6/2）继续把高能力 coding/security agents 推向生产安全场景；面试答案应更强调工具效率、审计、人类确认与受控访问。
  • Infra 层今天有明确可落地更新：vLLM v0.22.1、Weaviate v1.38.0、Qdrant v1.18.2、LangChain Core 1.4.1，都适合转成“升级前怎么验证”的生产面试题。

Market Signals Worth Watching

  • Memory is becoming a first-class product/system layer, not just a RAG add-on. Watch for API exposure, user controls, and enterprise governance patterns.
  • Frontier coding/security agents are moving into controlled high-impact deployment. Watch Anthropic Glasswing and OpenAI Codex enterprise stories for emerging best practices.
  • Vector DB releases are emphasizing namespaces, nested filters, WAL recovery, resharding and optimizer safety: production RAG interviews are increasingly infra/SRE-heavy.
  • Multimodal model demos are becoming productized; watch for latency, cost, and eval frameworks around real-time multimodal agents.

New Interview Questions to Add

  1. How would you design a long-term memory system for an AI assistant that remains useful without preserving stale or sensitive information?
  2. What evals would you run before enabling personalized memory in an enterprise assistant?
  3. How do effort budgets or “thinking levels” change agent orchestration and cost-quality tradeoffs?
  4. How would you design an agent-optimized CLI for a model to safely interact with a developer platform?
  5. What can go wrong when upgrading a vector database that supports namespaces, nested filtering, and reindexing?
  6. How would you validate a vLLM upgrade in a multi-node serving deployment?
  7. How should a security-scanning AI agent be gated before it is deployed against critical infrastructure codebases?
  8. What metrics would you use to evaluate multi-tool agents beyond final task success?
  9. How do you design RAG systems when the vector DB optimizer, WAL recovery, snapshot streaming, or resharding can fail?
  10. What changes in application architecture when multimodal models support real-time video/audio/text interactions?
