Operating Rules

  1. Active ≤ 3: 如果 active 超过 3 个，先暂停/等待/归档一部分。
  2. 每个项目只需要一个 next_action: 下一步必须是 15–60 分钟内能执行的动作。
  3. Morning pick, evening close: 早上选 1–3 个 focus，晚上只记录 done / blocked / tomorrow candidate。
  4. 新想法先进 inbox: 不要打断当天 focus。
  5. Dashboard 负责决策，不负责堆任务: 项目页保留 context；任务页/queue 保留执行细节。
