2026-06-22 AI面试知识点更新

链接：rich-interview MOC · AI市场每日更新系统

Executive Summary

  • OpenAI 官方动态继续把 GPT-5.5 / GPT-5.4 放在应用、医疗、科研和企业治理场景中；面试题应更强调模型选择、评测、成本控制与垂直场景安全，而不只是“调用最新模型”。Interview impact：候选人需要能解释 frontier model 如何落到企业 LLMOps、domain evals 和 risk controls。
  • Anthropic Claude Platform release notes 显示旧 Claude Sonnet 4 / Opus 4 API model IDs 已退休，同时 Fable 5 / Mythos 5 在 6 月上旬经历 launch 与访问限制变化。Interview impact：多模型系统必须把 model lifecycle、fallback、deprecation monitoring 当作一等设计。
  • Google Gemini API 近期新增 TTS streaming，并宣布 Imagen / Veo 旧 model IDs 退役时间；Google A2A 继续强化 agent-to-agent 协作叙事。Interview impact：agent/voice/multimodal 面试题应覆盖 streaming UX、deprecation migration、A2A vs MCP/tool-calling 的边界。

Market Signals Worth Watching

  • OpenAI enterprise adoption signal：Samsung 大规模部署 ChatGPT Enterprise + Codex。Interview impact：企业面试越来越会问“如何把 coding agents 安全地推到组织级”，而不是只问个人 productivity。
  • Model lifecycle volatility signal：Anthropic launch / suspension / retirement 与 Google deprecations 都说明 model IDs 和 availability 变化频繁。Interview impact：需要把 model registry、provider abstraction、release-note monitoring 纳入系统设计答案。
  • Agent privacy signal：MosaicLeaks 把“外部检索 query 泄露 private context”变成可测试风险。Interview impact：agent 安全面试题应从 prompt injection 扩展到 data exfiltration through tool calls。
  • Voice/multimodal streaming signal：Gemini TTS streaming 与 Veo/Imagen migration 说明 multimodal 产品更需要 latency、体验和兼容性测试。Interview impact：voice agent / multimodal RAG 题应覆盖 streaming protocol 和 regression testing。

New Interview Questions to Add

  1. 你负责一个多供应商 LLM 应用，Anthropic / Google 某些 model IDs 突然 deprecate 或被限制访问。请设计 model registry、fallback、canary、监控和回滚方案。Interview impact：考察生产级可靠性和供应商风险管理。
  2. 如果企业部署 ChatGPT/Codex 给数万员工，如何设计 usage analytics、spend controls、权限、代码数据隔离和安全审计？Interview impact：考察企业 LLMOps，而非 demo 级 agent。
  3. Deep research agent 需要读取私有文档并调用外部 web search。如何防止 search query 泄露私有信息？Interview impact：考察 agent privacy、tool policy、query rewriting 与审计。
  4. Voice agent 使用 TTS streaming 时，如何优化首包延迟、支持用户打断、处理 stream cancellation，并监控端到端体验？Interview impact：考察 realtime AI system design。
  5. RAG pilot 在 1k docs 可用，但扩到 50M rows 后 ingest 失败。你会如何设计批处理、错误恢复、embedding rate-limit、schema 和成本控制？Interview impact：考察 production RAG 而非 toy retrieval。
  6. 对生命科学/医疗类 AI 助手，如何构造 domain-specific benchmark 与 physician-informed eval？Interview impact：考察高风险垂直场景评测。
